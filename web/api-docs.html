TRUVOID / AGENCY API

Connect every outlet to one trusted verification layer.

Agency administrators can create an API key for each outlet. Keys are shown once, stored as hashes, and restricted to the outlet that owns them.

Authentication

Send the outlet key with every request using the X-API-Key header.

X-API-Key: trv_live_<your-key>

Reserve a verification call

POST/v1/tenant/verification-calls/reserve 
{
  "verificationType": "nin",
  "subjectRef": "hashed-subject-reference",
  "idempotencyKey": "outlet-request-123"
}

The request is charged against the outlet wallet. Reusing an idempotency key returns the original reservation instead of charging twice.

Manage keys

GET/v1/tenant/api-keys

List the agency's outlet keys. Secret values are never returned.

POST/v1/tenant/api-keys/outlets/{outletId}

Generate a key. The response contains rawKey once; store it securely immediately.

{ "description": "Lagos outlet production integration" }
DELETE/v1/tenant/api-keys/{id}

Revoke an outlet key. Revoked keys stop authenticating immediately.

Platform administration

Platform administrators can create an organization-scoped or outlet-scoped key through POST /v1/admin/api-keys/tenants. This endpoint is restricted to the platform admin policy.
